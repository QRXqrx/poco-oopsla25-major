# Artifact for PoCo (OOPSLA'25)

This repository contains the current version of the artifact. The artifact supports running key experiments described in the paper.

## Project Structure

- The artifact includes: source code, partial scripts, test data.
- The steps X, Y, Z are tested and reproducible.
- Some parts are under development and will be completed in the final version.

## Installation

> How to install PoCo on your own machine.

## Quick Start

> How to run PoCo on an example project, or, just on hello.

1. Clone the repo: `git clone ...`
2. Install dependencies (see below).
3. Run: `python run_exp.py config.yaml`
